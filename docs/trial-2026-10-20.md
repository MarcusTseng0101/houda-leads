# 20 家真實試跑（2026-10-20）

來源：data.gov.tw 6569「登記工廠名錄」（2026-09 版）→ 初篩（26～29 類、股份有限公司）12,902 家 → 隨機抽 20 家（種子 20261020）。
官網：由子代理用搜尋找候選網址（自動找官網還沒做），再由工具用統編／公司名確認。只用關鍵字，沒有 LLM。

## 數字

| 項目 | 結果 |
|---|---|
| 找到官網 | 15／20（5 家只出現在求職網、名錄；1 家 2024 年已解散，工廠登記沒更新） |
| 官網抓得到 | 10／15 |
| 抓不到的原因 | robots.txt 回 500（2 家，照 RFC 9309 當成全部禁止）、連不上（1）、擋程式 403（2：其中 1 家換成瀏覽器 UA 就能進，**我們不偽裝**） |
| 官網確認（統編或公司名） | 9／20 |
| 被列為潛在客戶 | 2／20，**兩家都判錯**（見下） |
| 命中多類送人工 | 4 |
| 有網頁但沒中任何關鍵字 | 4 |
| 對禁止網域的請求 | 0 |
| 每家平均 | 10.3 秒（主要是同網域 2 秒間隔）；12,902 家依序跑約 37 小時 |

## 關鍵字判斷錯在哪（看證據原文得出的，不是猜的）

1. **把「對方的客戶做什麼」當成「對方做什麼」。** 統懋半導體做整流二極體、MOSFET（元件），官網「產品應用」列了電源供應、UPS、BMS → 被判成電源設備廠。
   產業表自己就提醒「IC 或元件公司不一定直接使用端子台」。
2. **一個大類詞就決定。** 星昶國際做汽機車零件的板金加工，只因為「汽車」「機車」被判成交通設備。
3. **英文官網。** 大研金屬官網只有英文，關鍵字表幾乎都是中文 → 一個都沒中。
4. **選單文字混進證據。** 證據片段常帶到導覽列（「關於統懋 公司簡介 公司歷程…」），可讀性差。

## 對下一步的意義

- 關鍵字適合**初篩和提供證據**，不適合當最後判斷：它分不出「做什麼」和「提到什麼」。這正是 LLM（第 4 步）要做的判斷，
  而且輸出仍然要受「產業只能 18 類之一＋證據逐字在原文」約束。
- 要知道準確率，需要人工標的 gold：這 20 家可以當第一批（out/trial20/leads.xlsx）。
- 時間的槓桿：同網域間隔是每個網域各自算，可以**多個網域同時抓**（例如 8 個併發 → 約 5 小時），不必把間隔調短。
- 最大的成本其實是**找官網**：子代理用搜尋 20 家花約 6.5 分鐘，還碰到搜尋服務每分鐘 10 次的上限；12,902 家需要付費搜尋 API。
